# Velora Events v2

Complete multi-page-feel SPA built with React + TypeScript + Vite. Hash URLs are used so it works on static hosting without server rewrites.

Pages: Home, About, Services, Portfolio, Gallery, Packages, Blog, FAQ, Careers, Contact. Portfolio event modal, gallery lightbox, filters, search, testimonial slider, multi-step quote wizard, forms, mobile navigation and responsive layouts included.

Run: `npm install` then `npm run build`. Deploy the `dist` folder. Demo forms are front-end only and should be connected to a backend/email/CRM for production.
